# Statistical Analysis and Calibration

This directory contains the scripts responsible for the exploratory data analysis, parametric distribution fitting, copula dependence estimation, and information-asymmetry scenario definitions.

These scripts fulfill **Specific Objective 2** of the thesis:
> *Classify public tender procedures into information asymmetry scenarios (Low, Medium, and High) based on the recorded volume of consultations and observations, and estimate their governing probabilistic parameters.*

---

## Workflow Overview

| Script | Title | Methodological Role |
|---|---|---|
| `04_exploratory_analysis.py` | Exploratory Analysis & Diagnostics | Descriptive statistics, entity-cluster bootstrap correlation intervals, family sensitivity, and variance decomposition |
| `05_scenarios_and_calibration.py` | Calibration & Scenario Definition | Location-scale Lognormal fitting, Hurdle model, Gaussian copula, and P25/P75 cutpoints |

## 1. Script 04 — Exploratory Data Analysis

### Purpose
`04_exploratory_analysis.py` describes the reference cohort of **2,004 eligible code-level records** generated by Script 03. The baseline dataset remains intact. Related records are retained and examined through explicitly labeled sensitivity views; 2,004 records must not be interpreted automatically as 2,004 independent procurement procedures.

All temporal variables are differences between **published schedule dates**, not independently verified actual event durations. Associations with Q are observational and **do not establish causal effects**.

### Variables and Temporal Definitions

**Q (`queries_observations_count`)** is the combined number of numbered consultation/observation records in the accepted document. It is not a count of individual questions within each record or a direct measure of information asymmetry. Verified no-formulation acts contribute Q = 0; missing counts are not replaced with zero.

| Variable | Start boundary | End boundary |
|---|---|---|
| `query_to_award_calendar_days` | Query formulation start | Award end |
| `query_close_to_award_calendar_days` | Query formulation end | Award end |
| `absolution_calendar_days` | Query formulation end | Absolution end |
| `integration_calendar_days` | Absolution end | Integration end |
| `post_integration_calendar_days` | Integration end | Award end |

The eleven adjacent variables follow the naming convention `<start>_to_<end>_calendar_days` and connect consecutive boundaries in this order:

```text
query_start -> query_end -> absolution_start -> absolution_end
-> integration_start -> integration_end -> offers_start -> offers_end
-> evaluation_start -> evaluation_end -> award_start -> award_end
```

Each boundary is read from `schedule_<boundary>_date`. Durations are calendar-date differences, without an inclusive +1. Adjacent intervals include both within-stage spans and waiting periods between stages; they sum to the start-to-award total. In particular, `absolution_calendar_days` includes the wait after queries close, and `integration_calendar_days` includes the wait after absolution ends. The start-to-award horizon also includes the query formulation window; the close-to-award horizon is retained for comparison and subsequent calibration.

### Key Methodological Features
- **Descriptive Statistics:** Reports sample means, standard deviations and variances (`ddof=1`), coefficient of variation, median, quartiles, P05/P10/P90/P95/P99, extrema, IQR, skewness, excess kurtosis, zeros, frequencies, and missingness. Quantiles use linear empirical interpolation; fractional quantiles do not imply fractional-day observations.
- **Non-Parametric Association:** Spearman rank correlation (ρ), with average ranks for ties, is the primary association summary. Pearson correlation (r) is supplementary. Neither establishes causality.
- **Entity-Cluster Bootstrap:** Uses 2,000 whole-entity resamples with replacement, seed `20261101`, and recalculates ranks in each resample. The reference cohort contains 681 entity clusters. Repeated records and both members of each documented family remain together. Reported 95% percentile intervals are pointwise and exploratory, not simultaneous confidence statements. They assume independent, exchangeable entity clusters and do not establish population representativeness. Finite-replicate counts are reported; intervals require at least 20 clusters and at least 90% finite resamples, with a minimum of 10 finite resamples.
- **Independence-Based Diagnostics:** Legacy Pearson/Spearman p-values and within-family Benjamini-Hochberg adjustments are retained for compatibility and labeled `IID_ONLY_NOT_ENTITY_DEPENDENCE_ADJUSTED`. They are not robust inferential evidence under entity dependence and do not support the dependence-aware conclusions.
- **Distribution Shape and Limited Variation:** Shapiro-Wilk decisions are not used for discrete, tied, clustered observations. The legacy diagnostic sheet distinguishes counts, constants, insufficient data, and calendar-day variables. In the reference cohort, `integration_start_to_integration_end_calendar_days` and `award_start_to_award_end_calendar_days` are zero for all 2,004 records, so their correlations are undefined, not zero. `integration_calendar_days` and `absolution_end_to_integration_start_calendar_days` are zero in 2,000 records and positive in only four. Their correlations and bootstrap intervals are particularly fragile and must not support firm inferential conclusions. Absolution start-to-end and offers start-to-end also have substantial zero mass: 1,965 and 1,966 records, respectively. Coincident published dates do not prove absence of work.
- **Heterogeneity:** Provides profiles by notice year, entity type, and individual entity. Group-specific associations require at least 20 records and variation in both variables; this is a reporting rule, not a baseline exclusion. Pooled centered within-group fractional-rank correlations require at least three records and variation, report their own contributing sample sizes, and are distinct descriptive estimands without causal-adjustment claims.
- **Variance Decomposition:** Checks the additive variance identity and reports interval covariances. This diagnoses the consequences of independent interval sampling; it does not establish a causal mechanism or select a dependence model.
- **No Trimming:** Observations outside 1.5 × IQR remain in the baseline. With IQR = 0, flags describe concentration and are not automatic errors. No imputation, scenario assignment, distribution fitting, or definitive deduplication is performed.

### Related Families and Sensitivity Views

| Family | Records | Documentary interpretation |
|---|---|---|
| Comas | `811044` / `848861` | Same procedure and item; the later fiche records a restart from technical-proposal admission and a different award episode |
| Olmos | `995451` / `1058629` | Same mixed road/pedestrian procedure; the initial record covers items 1 and 3, while the restarted record concerns item 2 |

Within each family, the accepted consultation/observation PDF is identical. Later evaluation and award boundaries differ. These are related observations; the Olmos records must not be treated as simple interchangeable duplicates because their item coverage differs.

Six views compare means, standard deviations, quantiles, and associations with Q:

| View | n | Family records retained |
|---|---:|---|
| Full reference cohort | 2,004 | All four |
| Exclusion of both families | 2,000 | None |
| One per pair, alternative 1 | 2,002 | `811044`, `995451` |
| One per pair, alternative 2 | 2,002 | `811044`, `1058629` |
| One per pair, alternative 3 | 2,002 | `848861`, `995451` |
| One per pair, alternative 4 | 2,002 | `848861`, `1058629` |

The n = 2,002 alternatives are **sensitivity analyses, not definitive deduplications**. They do not determine which episode or item should represent a procedure in a final inferential model. Sensitivity comparisons describe observed changes; they are not formal tests of equivalence. Reporting flags use changes greater than 1% for means/standard deviations, one original unit for quantiles, and 0.02 for correlations. These thresholds are descriptive aids, not validated engineering equivalence margins.

From the repository root, use a fresh independent output root:

```bash
python 01_scripts/02_statistical_analysis/04_exploratory_analysis.py --project-root . --output-root 02_results/reproducibility/script04_run_001 --bootstrap-reps 2000 --seed 20261101
```

`--project-root` locates the existing Script 03 input. `--output-root` is required and contains the usual `02_results/` and `03_logs/` subdirectories. The script refuses an existing analytical output directory and does not replace official results. It validates staged workbooks before publishing the complete directory and verifies that source Excel files and existing 00–03 outputs retain their SHA-256 values.

Run the automated tests separately:

```bash
python 01_scripts/02_statistical_analysis/04_exploratory_analysis.py --self-test
```

The **18 synthetic tests** cover statistics, missing and invalid data, identifiers, temporal arithmetic, tied ranks, bootstrap reference calculations and reproducibility, cluster support, constants, BH adjustment, all sensitivity memberships, group support, variance decomposition, output integrity, corruption, and write failures. They use temporary synthetic data and do not execute scripts 00–03.

### Reference Execution and Limitations

The controlled reference execution completed successfully in one attempt, with **62 quality controls and no failures**. All eight output hashes were verified, and the 12 source Excel files and ten existing 00–03 output files retained their hashes.

| Horizon | Mean (days) | Standard deviation (days) | Median (days) | Spearman ρ | Pointwise entity-cluster 95% interval |
|---|---:|---:|---:|---:|---|
| Query start to award end | 63.469 | 46.794 | 45 | 0.4317 | 0.3768–0.4859 |
| Query close to award end | 48.733 | 46.168 | 31 | 0.4236 | 0.3682–0.4778 |

Across the five sensitivity alternatives, total-horizon means changed by at most 0.078 days, standard deviations by 0.023 days, and Spearman correlations by 0.00186; both medians remained unchanged. This stability does not extend automatically to every interval tail: the query-window P99 decreased from 27.97 to 26.01 days when all four related records were excluded, and the offers-end-to-evaluation-start P95 decreased from 13.85 to as low as 12 days.

These results support descriptive and exploratory use of the reference cohort. They do not validate actual event durations, establish causal effects, resolve the final treatment of restarts and items, or approve the later calibration and simulation stages. Sparse-interval uncertainty, institutional/year heterogeneity, and the entity-bootstrap assumptions must remain explicit.

## 2. Script 05 — Scenarios and Calibration

### Purpose
`05_scenarios_and_calibration.py` calibrates the conditional stochastic distributions for each tender stage and establishes the information-asymmetry partitions.

### Key Methodological Features
- **Location-Scale Parameterization:** Standardizes Q into z = [ln(1 + Q) − 2.741] / 1.188 and estimates continuous parameters via maximum likelihood:
  - Stage 1 (Absolution): Lognormal with conditional location: a = 2.293, b = 0.458.
  - Stage 2 (Integration): Two-part Hurdle model (p_zero = 0.998; 99.8% duration is 0 days; empirical mixture when positive).
  - Stage 3 (Post-Integration to Award): Lognormal with conditional location and scale: a = 3.119, b = 0.129, c = −0.439, d = 0.136.
- **Multivariate Gaussian Copula:** Models inter-stage dependence using randomized Probability Integral Transform (PIT) to handle zero-mass points cleanly.
- **Asymmetry Scenarios:**
  - **Primary Scheme (P25 - P75):** Low (Q < 7), Medium (7 ≤ Q ≤ 35), High (Q > 35).
  - **Sensitivity Scheme (Tertiles):** Low (Q ≤ 10), Medium (11 ≤ Q ≤ 27), High (Q > 27).
- **Group-Balanced 5-Fold Cross-Validation:** Allocates procedures into 5 project-balanced folds to avoid CUI/entity leakage.

### Execution
From the repository root:
```bash
python 01_scripts/02_statistical_analysis/05_scenarios_and_calibration.py
```

### Main Outputs (`02_results/02_statistical_analysis/`)
- `05_1_classified_dataset.xlsx`: The 2,004 procedures with assigned scenario labels and fold indices.
- `05_2_calibration_audit.xlsx`: Model selection tables (AIC/BIC), transition matrices, and parameter audits.
- `05_3_model_parameters.json`: Complete calibrated specification and copula matrix used by the simulation engine.
- `05_cv_models/`: Calibrated parameters for each of the 5 cross-validation training folds.
