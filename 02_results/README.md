# Analytical Results and Research Artifacts

This directory houses the structured analytical datasets, econometric model specifications, simulation outputs, and validation audits generated by the computational pipeline.

The approved local runs preserve their inputs, settings and output hashes in manifests. The inventory below describes the current contracts.

---

## Directory Organization

The results workspace is partitioned into four modular directories matching the research pipeline:

```text
02_results/
│
├── 01_sample_and_data/          # Master datasets, acquisition audits, and quality control
├── 02_statistical_analysis/     # Exploratory statistics, model parameters, and CV folds
├── 03_stochastic_simulation/    # Monte Carlo precision and conditional simulation summaries
└── 04_model_validation/         # Internal diagnostics, marginal OOF evaluation, and sensitivity
```

## Reproducibility Statement

Approved controlled runs are stored under `02_results/reproducibility/` in the local workspace. Consult the [script execution guide](../01_scripts/README.md) for required inputs and output roots. A clean clone does not contain the approved artifacts. Broad local exclusions in `.git/info/exclude` must be configured separately on each clone. Verify representative paths with `git check-ignore` before staging any files.
