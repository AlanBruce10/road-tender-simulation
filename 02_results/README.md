# Analytical Results and Research Artifacts

This directory houses the structured analytical datasets, econometric model specifications, simulation outputs, and validation audits generated by the computational pipeline.

All results are fully auditable, deterministic, and reproducible from the raw source datasets using the sequential Python scripts in `01_scripts/`.

---

## Directory Organization

The results workspace is partitioned into four modular directories matching the research pipeline:

```text
02_results/
│
├── 01_sample_and_data/          # Master datasets, acquisition audits, and quality control
├── 02_statistical_analysis/     # Exploratory statistics, model parameters, and CV folds
├── 03_stochastic_simulation/    # Monte Carlo convergence audits and DES simulation summaries
└── 04_model_validation/         # Goodness-of-fit tests, hypothesis decisions, and sensitivity
```

## Reproducibility Statement

Large temporary simulation files (such as raw trajectory files exceeding 50 MB) are excluded from the GitHub tracking repository via `.gitignore`. 

Any researcher can regenerate the complete workbook collection and all analytical figures by executing the computational pipeline from the repository root as described in `01_scripts/README.md`.
